\section{Постановка задачи}
В качестве решаемой задачи в данной работе была выбрана задача Дирихле для уравнения Пуассона. Уравнение Пуассона - эллиптическое дифференциальное уравнение в частных производных, описывающее обширный класс объектов: электростатическое поле, поле давления, адиабатный процесс и т.д. Уравнение имеет вид
\begin{equation}
  \Delta\phi=f
\end{equation}
где $\Delta$ - оператор Лапласа, $f$ - вещественная или комплексная функция на некотором многообразии.

Конкретизируем задачу. Пусть $u=u(x,y)$ - искомая функция, $D$ - область определения, $g(x,y)$ - краевые условия, $D^0$ - граница области $D$, $f=f(x,y)$ - заданная функция. Тогда уравнение принимает вид:
\begin{equation}
  \begin{cases}
    \dfrac{\delta^2u}{\delta x^2}+\dfrac{\delta^2u}{\delta y^2}=f(x,y), &\text{$(x,y) \in D$}\\
    u(x,y)=g(x,y), &\text{$(x,y) \in D^0$}
  \end{cases}
\end{equation}
За область определения $D$ примем единичный квадрат
\begin{equation}
  D=\{(x,y) \in D: 0 \le x,y \le 1\}
\end{equation}
Дискретизируем систему, применив метод конечных разностей (метод сеток)
\begin{equation}
  \begin{cases}
    D_h=\{(x_i,y_j): x_i=ih, y_j=jh, 0 \le i,j \le N+1\}\\
    h=1/(N+1)
  \end{cases}
\end{equation}
где $N$ - количество узлов по каждой из координат области $D$.

Обозначим аппроксимацию функции $u(x,y)$ в точке $(x_i, y_i)$ через $u_{ij}$. Тогда уравнение Пуассона в конечно-разностной форме принимает вид:
\begin{equation}
  \dfrac{u_{i-1,j}+u_{i+1,j}+u_{i,j-1}+u_{i,j+1}-4u_{ij}}{h^2}=f_{ij}
\end{equation}
Относительно $u_{ij}$:
\begin{equation}
  u_{ij}=\dfrac{u_{i-1,j}+u_{i+1,j}+u_{i,j-1}+u_{i,j+1}-h^2f_{ij}}{4}
\end{equation}
Таким образом, задача сводится к решению системы линейных алгебраических уравнений
